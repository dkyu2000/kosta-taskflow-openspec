# Mobile Spec

## Purpose

모바일(768px 미만) 환경에서의 UI/UX 적응형 동작을 담당한다. 칸반 1컬럼 탭 스와이프, 햄버거 메뉴, 채팅 키보드 대응 기능을 제공한다.

## Requirements

### Requirement: 모바일 칸반 1컬럼 탭 스와이프
768px 미만 화면에서 칸반 보드는 3컬럼 대신 1컬럼으로 표시되어야 하며(SHALL), 상단 탭(TODO / DOING / DONE)으로 컬럼을 전환하고 좌우 스와이프로 이동할 수 있어야 한다.

#### Scenario: 모바일 칸반 진입
- **WHEN** 768px 미만 화면에서 칸반 화면을 열면
- **THEN** 3컬럼 대신 상단에 TODO / DOING / DONE 탭 인디케이터와 현재 선택 컬럼 1개만 표시된다

#### Scenario: 탭 클릭으로 컬럼 전환
- **WHEN** 사용자가 상단 탭에서 DOING을 클릭하면
- **THEN** DOING 컬럼의 카드 목록이 표시되고 탭 인디케이터가 DOING으로 활성화된다

#### Scenario: 좌우 스와이프로 컬럼 전환
- **WHEN** 사용자가 칸반 영역에서 좌측으로 스와이프하면
- **THEN** 다음 컬럼(TODO→DOING→DONE 순)으로 전환된다

#### Scenario: 우측 스와이프로 이전 컬럼 이동
- **WHEN** 사용자가 칸반 영역에서 우측으로 스와이프하면
- **THEN** 이전 컬럼(DONE→DOING→TODO 순)으로 전환된다

---

### Requirement: 모바일 햄버거 메뉴
768px 미만 화면에서 헤더의 탭 버튼(칸반/채팅/멤버)은 숨겨지고 ≡ 햄버거 버튼으로 대체되어야 한다(SHALL). 햄버거 메뉴를 누르면 풀스크린 슬라이드 패널이 열리며 사용자 정보, 칸반·채팅·멤버·로그아웃 항목을 제공한다.

#### Scenario: 햄버거 버튼 표시
- **WHEN** 768px 미만 화면에서 칸반 또는 채팅 화면을 열면
- **THEN** 헤더 좌측에 ≡ 버튼이 표시되고 탭 버튼은 숨겨진다

#### Scenario: 햄버거 메뉴 열기
- **WHEN** 사용자가 ≡ 버튼을 클릭하면
- **THEN** 사용자 이메일·팀명과 칸반/채팅/멤버/로그아웃 항목이 있는 슬라이드 패널이 화면을 덮는다

#### Scenario: 햄버거 메뉴에서 화면 전환
- **WHEN** 사용자가 슬라이드 패널에서 채팅을 선택하면
- **THEN** 패널이 닫히고 채팅 화면으로 전환된다

---

### Requirement: 모바일 채팅 입력 키보드 대응
768px 미만 화면에서 채팅 입력창에 포커스가 생기면 메시지 목록 영역이 자동으로 축소되어 키보드에 가려지지 않아야 한다(SHALL).

#### Scenario: 키보드 활성화 시 메시지 영역 축소
- **WHEN** 모바일에서 채팅 입력창을 탭하여 키보드가 올라오면
- **THEN** 메시지 목록 영역이 남은 공간에 맞게 축소되고 입력창이 키보드 위에 위치한다
